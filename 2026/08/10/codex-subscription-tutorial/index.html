从零开始：美区 ID + 科学上网 + 海外银行卡 + 境外手机号接码 + Codex 正规订阅史上最全教程

Codex Apple ID 科学上网 海外银行卡 ChatGPT
教程
发布日期:   2026-08-10

给大家分享一篇个人从零到一订阅 ChatGPT、Codex、Claude 的教程

这套从 0 到 1 的流程包括：

科学上网

美区 ID 注册

海外银行卡办理

美国手机号接码

CodeX 正规订阅

其中涉及到的门道，对于从 0 到 1 的小白来说，可以说不亚于写一篇论文了，稍有不慎就会陷入环环相扣的境地，需要C的前提下首先要有B，需要B的时候必须要有A，需要A的时候但先要有C。所以，我想出一个史上最全的教程，教你从什么都不会的小白，到可以亲手完成以上所有流程。

当然，我知道能来到这里观看的朋友，肯定已经有了科学上网的办法。不过这个教程的另外一个用处，就是当你想帮身边的家人或朋友时，如果他们问起其中任何一个环节，你可以直接把这篇文章丢给他们，直接帮你省掉大批教小白的时间。

话不多说，进入正文。

你需要准备什么？

一台 Mac 和一部 iPhone。本文以苹果生态为例，但是安卓和 Windows 的用户也完全可以作为参考，本人日常是一台小米和一部 iPhone 双持，电脑是大学上学时期的一部拯救者和一台 Mac 也双持，可以说是习武之人了。其中的大部分流程其实都是相通的。

第一章：注册美区 Apple ID

为什么一定要美区 ID？

因为国区的 App Store 是没有小火箭（也就是 Shadowrocket）的，你也下不到 ChatGPT 的官方 App。任何海外的、没有引进国内的 App，你都无法在国区 ID 中，并且在不翻墙的情况下进行下载。

所以你需要一个美区 ID，并且翻墙之后，就可以自由下载这些软件了

注册前需要准备什么？

一个没注册过 Apple ID 的邮箱、一个能收验证码的手机号——可以是 +86

手把手注册美区 ID 的具体步骤（全程不需要梯子）

第一步：打开 Apple 账户注册页面

需要打开注册 Apple 账户的网址：http://appleid.apple.com。

第二步：创建 Apple 账户

打开这个网址之后，选择创建你的apple账户，随便填一个名字，地区选美国，随便填一个 18 岁以上的生日，然后在手机号那一栏填你自己的国内手机号即可。

第三步：登录 App Store 并搜索 Shadowrocket

打开 App Store，登录你刚刚注册的账号，然后搜索 Shadowrocket，你就会发现以前在墙内下不到的软件已经出现了

到这里，你就已经拥有一个美区 ID 了，只不过这个 ID 还没有绑定支付方式。但是你已经可以看到很多国区 ID 下不到的软件了。接下来，我们要搞定的就是美区 ID 的支付。

第二章：购买并下载小火箭（Shadowrocket）

小火箭是什么？为什么必须先买它？

小火箭就是 Shadowrocket，需要在Apple Store 上花 2.99$ 购买，是 iOS 上最主流、最好用的代理客户端 App。你可以把它理解成一个“播放器”，而你需要购买的 VPN 订阅链接就相当于“视频资源”——播放器本身不产生内容，但有了它才能播放你买的资源。

为什么必须先买它？因为你的目标是让 iPhone 能科学上网，而 iOS 上最靠谱、最易用的翻墙工具就是小火箭。它支持各种代理协议（比如你电脑上已经在用的那些配置），并且能直接导入你电脑上的梯子订阅链接，无缝打通手机和电脑两端。

最关键的是：国区 App Store 没有小火箭，它只上架在美区。所以“买小火箭”这个动作，本质上是在逼你完成一个前置任务——注册美区 Apple ID。这是整条链路里最绕不开的一步，搞定了它，后面所有的美区应用（ChatGPT、X 等）才都能下载。

简单说：小火箭是你 iPhone 翻墙的“钥匙”，而美区 ID 是拿到这把钥匙的“门票”。

两种方式购买并下载小火箭

方案 A：使用苹果礼品卡购买（适合没有任何海外支付方式的人）

Step 1：解锁支付宝“隐藏”入口

支付宝针对出境用户有专门的界面。

1. 打开支付宝，点击左上角的当前城市。

2. 在顶部选项卡切换到「国际/港澳台」。

3. 左侧栏选择「北美洲」，城市随便选一个，例如「旧金山」。

Step 2：购买 Apple 官方礼品卡

界面会自动刷新，点击底部的「惠出境」或「优惠」（UI 因版本不同略有差异）。

1. 找到中间的「热门礼品卡」入口点击进入。

2. 下滑找到 Apple 图标，点击「去购买」。

3. 输入金额：支持小额充值（最低 $2）。

4. 薅羊毛：记得点一下底部的「用积分获取折扣」，能省一点是一点。

5. 支付：点击「去付款」，首次可能需要验证身份，随后直接用人民币支付，汇率透明。

Step 3：在 App Store 兑换激活

支付成功后，复制页面显示的 SN 兑换码。

1. 转到 App Store，确保已登录你的美区账号。

2. 点击头像 → Redeem Gift Card or Code → Enter Code Manually。2. 点击头像 → 兑换礼品卡或代码 → 手动输入代码。

3. 粘贴代码，充值到账！

方案 B：绑定海外银行卡直接购买

具体方法见第六章。

第三章：搞到一个能用的梯子（VPN 订阅）

小火箭 = 客户端（飞机场里的“飞机”）；VPN 订阅 = 航线（机场节点）。小火箭本身只是一个空壳 App，需要导入“订阅链接”或“节点信息”才能翻墙。订阅链接相当于你买的“机票”，告诉你飞到哪条线路上去。

如何选择一个靠谱的机场服务商？

市面上机场服务商非常多，每个人用的可能都不一样。有一个现实你需要先知道：没有人希望自己用的机场节点被太多人使用，因为用的人越多，对应机房 IP 就越容易被各大网站标记为“不干净”，导致验证码频出、账号风控等问题。

所以我的建议是：不要一味追求最便宜或用户量最大的机场，而是选择那些节点更新及时、线路稳定、客服能及时响应的中小型服务商。

以下是几个硬性筛选标准：

• 支持 Clash 订阅链接 或 Shadowrocket 直接导入（这是小火箭能用的前提）；

• 有至少 3～5 条不同地区的节点（美、日、新、台等）；

• 客服响应速度在 24 小时内（TG 群 / 工单系统）；

• 支持按流量或按时长付费，不需要长期捆绑。

实话实说：我日常也是几个机场换着用，但目前测下来，没有一个能从头到尾一直保持百分百稳定。 遇到高峰期卡顿、节点被墙封锁是常态，所以我已经在考虑自己搭建 VPS 了。 感兴趣的小伙伴可以关注我，后续我会分享从零搭建 VPS 的完整教程。

购买订阅后，如何获取订阅链接 / 二维码

付款成功后，机场服务商一般会给你一个“用户中心”或“仪表盘”页面。登录进去，找到类似这样的按钮或标签：

• 一键订阅

• 订阅地址

• Clash 订阅链接

• 导入 Shadowrocket

点击后，你会看到一串很长的网址（以 https:// 开头，后面跟着一堆随机字符），这就是你的订阅链接。同时，页面上通常也会生成一个对应的二维码，方便你直接用手机扫码导入。

注意：订阅链接相当于你机场账号的“钥匙”，不要随意分享给他人，否则别人会占用你的流量和节点。

如何在小火箭中导入订阅并开启连接

拿到订阅链接后，在 iPhone 上打开小火箭，按以下步骤操作：

方法一：扫码导入（最快）

1. 打开小火箭，点击左上角的扫描按钮（二维码图标）；

2. 对着电脑屏幕上的订阅二维码扫一下；

3. 小火箭会自动识别并导入所有节点。

方法二：手动粘贴订阅链接

1. 在小火箭主界面，点击右上角的 “+” 号；

2. 选择 “类型” 为 Subscribe（订阅）；

3. 在 “URL” 栏中粘贴你复制好的订阅链接；

4. 点击 “完成”，小火箭会自动拉取节点列表。

导入成功后，你会看到一排节点名称（比如“美国-洛杉矶”、“日本-东京”、“新加坡”等）。

开启连接

1. 选择一个节点（一般选延迟最低的）；

2. 点击主界面右上角的开关，按钮变为蓝色即表示连接成功；

3. 首次开启时，系统会弹窗提示“是否允许添加 VPN 配置”，点击 Allow / 允许，并验证你的面容 ID 或密码。

测试是否翻墙成功

连接成功后，别急着关掉页面，先做个简单测试：

1. 打开 iPhone 自带的 Safari 浏览器；

2. 输入网址：www.google.com；

3. 如果能正常打开 Google 搜索页面，说明翻墙成功；

或者也可以直接打开 YouTube / Twitter（X）测试是否能正常加载内容。

如果 Google 打不开，或者显示“无法连接”，先检查小火箭的开关是否打开，再换一个节点重试。还是不行的话，回头检查订阅链接是否复制完整（注意不要多复制空格或换行符）。

第四章：注册 ChatGPT 账号

搞定了梯子之后，现在可以正式开始注册 ChatGPT 了。

注意： 注册全程建议保持代理开启（节点选美国或日本等非敏感地区），否则可能直接看不到注册入口或被重定向到限制页面。

第一步：访问官网

用电脑或手机的 Safari / Chrome 浏览器打开： https://chat.openai.com

点击页面上的 “Sign up” 按钮。

第二步：选择注册方式

目前 ChatGPT 支持以下几种注册方式：

• Google 账号（推荐）

• Apple 账号（推荐）

• 邮箱（国内邮箱如 QQ / 163 也可,亲测没问题）

我个人推荐用 Gmail 注册，成功率更高。如果你已经有 Gmail，直接点 Google 登录即可。如果没有，也可以用邮箱注册，但建议尽量用海外邮箱。

第三步：设置密码

按要求设置密码（至少 8 位，含大小写字母和数字）。设置完成后，系统会向你填写的邮箱发送一封验证邮件。

主包在自己走这个流程的时候，不知道为什么它没让我设置密码。不过 OpenAI 也是想一出是一出，可能到你们注册的时候还是需要走这一步的。

第四步：邮箱验证

去你的邮箱收件箱找到 ChatGPT 发来的验证邮件，点击验证链接完成邮箱确认。

如果没收到，检查垃圾邮件箱，或点击页面上的“重新发送验证邮件”。

第五步：填写个人信息

按要求填写姓名（随便填英文名即可）和出生日期（确保年满 18 岁）。

第六步：手机号验证（关键步骤）

走到这一步，绝大多数人会遇到 OpenAI 的手机号风控。比如之前我在线下给老板弄的时候，因为老板的梯子质量比较差，就出现了手机号风控。

不过这一次我自己重走这个流程的时候，因为用的是非国行的 iPhone，搭配美区的 ID 和美国的 IP 节点，可以说是非常 native 了，所以没有出现这一步。

这里只有之前拍照留下的一个截图。

页面会要求输入一个手机号接收短信验证码，不允许填写+86（中国大陆）号码。

那么怎么搞到一个能用的海外手机号进行接码呢？详见下一章。

第七步：注册成功

输入验证码后，恭喜你，ChatGPT 账号注册完成！你会直接进入 ChatGPT 的聊天界面，可以开始免费使用 GPT 了。

目前免费版用户可以使用 GPT-5.5 Instant 模型。如果你需要更强的推理能力和更多使用额度，可以继续看第六章完成订阅。

第五章：搞定国外手机号接码（绕过 OpenAI 风控）

前面说了，+86 手机号注册不了 ChatGPT。这里提供两种解决方案，按推荐程度排序。

方案一：闲鱼搜索 “Codex 号码援助”（推荐）

这个是当前最稳、最快捷的办法：

1. 打开手机淘宝 / 闲鱼 App；

2. 搜索关键词 “Codex 号码援助”（注意是 Codex，不是 ChatGPT，后者已经被屏蔽）；

3. 找一家评价好、成交多的卖家；

4. 跟卖家说你要接 ChatGPT 的注册验证码；

5. 卖家会给你一个海外手机号，你把那个号码填到 ChatGPT 注册页面；

6. 等几秒钟，卖家会把收到的验证码发给你；

7. 填入验证码，完成注册。

价格一般在几块钱到十几块不等，具体看市场行情。

优点： 简单省心，不用自己折腾接码平台。 缺点： 一次性的，换设备登录需要重新接码（但一般不会频繁触发）。

方案二：hero-SMS 等接码平台（备选）

如果你希望自己掌控，不想依赖闲鱼卖家，可以用这类接码平台：

1. 访问 https://hero-sms.com/cn 或类似的接码网站；

2. 注册并充值（通常支持支付宝付款）；

3. 在服务列表里选择 OpenAI / ChatGPT；

4. 平台会分配一个海外手机号给你；

5. 在 ChatGPT 注册页面填入该号码，等待接收验证码；

6. 在平台页面上查看收到的验证码，填入注册页面即可。

此方案有一定门槛（充值流程略麻烦），适合动手能力强的新手。

重要提醒

• 无论用哪种方式，请在 5 分钟内完成验证，验证码有时效；

• 如果第一次收不到，可以让卖家/平台换一个号码重试；

• 完成注册后，记得去 ChatGPT 设置里开启 双重验证（Two-Factor Authentication），保护你的账号。

第六章：搞定海外银行卡，正规订阅 Plus / Pro

免费版有使用额度限制，如果你需要：

• 更强的推理能力（如 GPT-5.5 Thinking 和 GPT-5.6 Sol 等模型）

• 更多的消息与上传额度

• 优先体验新功能

那就必须完成订阅，而订阅就需要一张 海外的银行卡。

注意：目前 ChatGPT 的订阅套餐包括 Plus、Pro、Business 和 Enterprise 等。Plus 和 Pro 是个人用户最常用的选项，其中 Plus 更适合进阶工作与高效办公，Pro 则面向研究和编程等更重度的使用场景。

为什么一定要海外银行卡？

因为 OpenAI 的支付系统只接受非中国大陆发行的信用卡/借记卡。国内普通的银联/Visa双标卡大概率会被拒绝（发卡行在中国境内就不行）。

我提供两个亲测可用的方案：

方案 A：Bitget U 卡（适合有 Crypto 经验的小伙伴）

这张卡的实际发卡行是 瑞士 Fiat24 银行，是一张正规的瑞士银行卡，所以完全符合 OpenAI 的支付要求。

优势

• 申请免费，几分钟搞定；

• 支持 USDC 充值（Arbitrum / 多链）；

• 直接生成完整的银行卡号、有效期、CVV；

• 绑定 ChatGPT 和 Apple ID 都亲测可用。

大致流程

1. 下载 Bitget Wallet App 或访问官网，注册并完成 KYC（身份认证）；

2. 在 App 内找到 “U 卡” 或 “Fiat24” 入口；

3. 按提示申请虚拟银行卡，几分钟内生成卡信息；

4. 向该卡充值 USDC（或其他支持的币种）；

5. 充值到账后，在 ChatGPT 订阅页面输入卡号、有效期和 CVV；

6. 完成订阅

主包因为已经有这个U卡了，没有办法再重走一遍这个流程了。

并且听说最近发卡行暂停了发卡服务，所以 Bitget 也在等待发卡行重新恢复服务。过段时间感兴趣的小伙伴们可以再试试。

这条路径适合已经有加密货币交易所账号的朋友。 如果你完全没接触过 Crypto，也没有任何交易所账号，可以跳过此方案，看下面的方案 B。

方案 B：招商银行全币种 Visa 卡（适合纯小白）

这个是 零门槛 的方案，个人亲测可用，而且办卡非常简单。

为什么这张卡能用？

招商银行的全币种信用卡虽然是国内银行发行，但它的清算走的是 Visa 境外通道，OpenAI 这边会把它识别为境外卡，所以可以顺利绑定和扣款。

办理步骤

1. 打开 招商银行 App（没有的话先下载注册）；

2. 在 App 首页搜索框输入 “全币种银行卡”；

3. 找到“全币种国际信用卡”并点击申请；

4. 填写个人信息，提交申请；

5. 招行客服会联系你确认，然后安排客户经理 上门面签（带身份证就行）；

6. 审批通过后，卡片会寄到你填的地址，收到后激活即可。

绑定到 ChatGPT

1. 在 ChatGPT 网页端，点击左下角的 “升级套餐 / Upgrade”；

2. 选择 Plus（$20/月）或 Pro（根据定价）；

3. 进入支付页面，输入你的招行全币种卡号、有效期和 CVV；

4. 账单地址填写真实地址（可填国内地址，也可以用转运地址）；

5. 点击确认，扣款成功即订阅完成。

绑定到 Apple ID（用于 App 内订阅）

1. 打开 iPhone 的 设置 → 点击顶部的 Apple ID；

2. 进入 “付款与配送” → 点击 “添加付款方式”；

3. 选择 “信用卡/借记卡”，输入招行全币种卡的信息；

4. 账单地址可以填美国地址（生成一个免税州地址更佳）；

5. 保存后，即可在 App Store 中正常订阅各类美区应用。

订阅成功后检查

完成订阅后，回到 ChatGPT 聊天界面：

• 左上角或左下角应该能看到 “Plus” / “Pro” 标识；

• 模型选择器里应该出现 GPT-5.5 Thinking、GPT-5.6 Sol 等高级模型选项；

• Codex 功能已包含在套餐内，可以直接使用。

至此，从零到完成订阅的整套流程全部走通。恭喜你，以后可以自由使用 ChatGPT 的全部功能了。

第七章：最终验收

走完前面所有的步骤之后，你已经完成了从零到一的全部流程。最终，你拥有的远不止是一个能用的 ChatGPT，而是一整套完整的“海外工具链”。

✅ 你已成功拥有的东西

1. 一个美区 Apple ID

• 可以自由登录美区 App Store；

• 可以下载任何美区专属应用（小火箭、ChatGPT、X、Claude、Notion 等）；

• 以后想下什么美区 App，再也不用求人借 ID 了。

2. 成功购买并下载了小火箭（Shadowrocket）

• 无论是通过礼品卡充值还是绑定银行卡支付，你已经完成了美区 App Store 的第一笔交易；

• 从此掌握了 iPhone / Mac 翻墙的“钥匙”。

3. 一个可用的机场订阅（VPN 节点服务）

• 你已经拥有了至少一个有效的订阅链接；

• 了解如何获取、更新、更换节点；

• 小火箭正常开启，iPhone 可以随时科学上网。

4. 用海外手机号成功接码并注册了 ChatGPT

• 你学会了如何获取海外虚拟手机号；

• 成功绕过了 OpenAI 的风控；

• ChatGPT 账号已绑定邮箱，随时可以登录使用。

5. 成功办理了一张海外银行卡

• 无论是 Bitget U 卡（瑞士 Fiat24）还是招行全币种 Visa；

• 你已经拥有了一张可以用于海外在线支付的工具；

• 这张卡不只是用在 ChatGPT 上，以后订阅其他海外服务（如 Claude Pro、Midjourney、Netflix 等）都可以用。

6. 成功订阅了 ChatGPT Plus / Pro

• 你的 ChatGPT 已解锁高级模型（如 GPT-5.5 Thinking、GPT-5.6 Sol 等）；

• 有更高的消息额度和上传额度；

• Codex 功能已包含在套餐内，可以正常使用数据分析、代码执行等高级功能。

走到这一步，你不仅拥有了一个随时可用的 ChatGPT Plus / Pro，更重要的是，你拥有了一套可以自主维护、持续使用的海外数字工具链。以后再遇到任何海外服务的注册或订阅需求，你都能自己搞定。

恭喜你，毕业了。
