穷鬼福音：用GLM-4白嫖Claude Code，这波赚大了

Claude Code 教程 GLM-4 AI 白嫖
技术教程
发布日期:   2026-01-05

穷鬼福音：用GLM-4白嫖Claude Code，这波赚大了前言：穷是真的穷前几天刚用 Claude Code 搭建了博客，那体验确实爽，跟真人对话一样，还帮我自动写代码、改配置。但一看价格——20美元一个月！ 算了算，20刀就是140多人民币，够我吃好几顿排骨了。作为个刚入门的小白，平时也就写写博客、改改配置，这钱花得心疼啊。 然后我就想，国内有没有平替？ 搜了一圈，还真让我找到了——智谱AI的GLM-4！ 关键是，它免费额度很大，而且效果还挺能打。今天就把我折腾的过程写下来，手把手教大家白嫖（不是）。 先说结论：效果怎么样？直接说感受吧： ✅ 写代码：日常使用足够，能理解上下文，知道我想干啥✅ 中文理解：毕竟是国产模型，这点比 Claude 强✅ 响应速度：感觉比 Claude 快，可能是国内服务器✅ 免费额度：新用户送一大堆，日常使用基本够用 ❌ 复杂推理：特别复杂的逻辑，感觉还是差点意思❌ 代码风格：偶尔会写一些奇怪的代码（但能跑） 总的来说，对于我们这种小白用户，完全够用！ 准备工作1. 注册智谱AI账号先去智谱AI开放平台：https://open.bigmodel.cn/ 注册流程很简单，手机号验证一下就行。 重点来了：注册完会送你免费额度！ 新用户：好像是送 25 元的额度 每天登录：还能领一些token 具体数量可能会变，反正日常使用肯定够了。 2. 创建 API Key登录后，右上角有个”API Key”，点进去： 点击”创建API Key” 给它起个名字，比如”Claude Code” 复制这个 Key（只显示一次，赶紧复制保存） 这个 Key 长这样： 1sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx 把它存好，等下要用。 3. 安装 Claude Code如果你还没装 Claude Code，先装一下： 12345# 使用 npm 安装npm install -g @anthropic-ai/claude-code# 或者用 pnpmpnpm add -g @anthropic-ai/claude-code 安装完，终端里输入 claude，应该就能看到欢迎界面了。 开始折腾第一步：找到配置文件Claude Code 的配置文件在： Mac/Linux: ~/.config/claude-code/config.json Windows: %APPDATA%\claude-code\config.json 如果文件不存在，可以先运行一次 claude，它会自动创建。 第二步：修改配置打开配置文件，会看到类似这样的内容： 1234{ “apiUrl”: “https://api.anthropic.com“, “apiKey”: “你的Claude官方Key”} 我们要把它改成这样： 123456{ “apiUrl”: “https://open.bigmodel.cn/api/paas/v4/“, “apiKey”: “你的GLM-4的Key”, “model”: “glm-4-plus”, “provider”: “glm”} 等等，这里有个坑！ Claude Code 原生不支持自定义 API，所以我们需要用个代理工具。 第三步：安装代理工具（踩坑实录）我当时直接改配置，结果报错了。查了一下才发现，Claude Code 只认 Anthropic 的 API。 于是找了半天，找到了这个工具：claude-code-proxy 安装方法： 123456789# 克隆项目git clone https://github.com/your-repo/claude-code-proxy.gitcd claude-code-proxy# 安装依赖npm install# 启动代理npm start 代理会在本地开一个服务，比如 http://localhost:8080 第四步：修改 Claude Code 配置现在再次修改配置文件： 12345{ “apiUrl”: “http://localhost:8080“, “apiKey”: “你的GLM-4的Key”, “model”: “glm-4-plus”} 第五步：测试一下打开终端，输入： 1claude 然后随便说点啥，比如： 1你好，用中文回复我 如果看到中文回复，恭喜你，成功了！ 踩坑记录（血泪史）坑1：代理起不来现象：启动代理时报错，端口被占用。 解决：换个端口，修改代理的配置文件，把 8080 改成别的，比如 8888。 坑2：Key 无效现象：提示 API Key 无效。 原因：我复制的时候多复制了个空格…真的无语。 解决：重新复制一遍，注意别带空格。 坑3：响应很慢现象：发个问题，半天不回。 原因：智谱 API 有时抽风，或者我网络有问题。 解决：多试几次，或者换个网络。 坑4：突然不能用了现象：用得好好的，突然报错。 原因：免费额度用完了。 解决：等第二天领新的，或者实名认证后能领更多。 实际使用体验体验1：写博客我试着让它写一篇博客： 1帮我写一篇关于如何使用 GLM-4 的博客，风格要接地气，别太正式 结果：写出来的东西还行，有那种感觉了，但还是有点 AI 味。我自己改了改就好了。 评价：✅ 能用，但需要自己润色 体验2：写代码让它帮我写个 Python 脚本： 1写个 Python 脚本，批量重命名文件夹里的图片 结果：代码能跑，但写法有点奇怪，变量名也不太规范。 评价：✅ 功能实现了，但代码质量一般 体验3：改配置让它帮我改 Hexo 配置： 1把 Hexo 的主题改成 matery，并且安装必要的插件 结果：它给我列了一堆命令，我照着执行，居然成功了！ 评价：✅ 这个很赞，不用自己去查文档了 体验4：解释代码有时候别人的代码看不懂，直接扔给它： 1解释一下这段代码是干什么的 结果：解释得挺清楚，比我自己看快多了。 评价：✅ 学习神器 对比一下：Claude vs GLM-4.7 项目 Claude GLM-4 价格 20刀/月 20￥ 中文理解 还行 很好 代码质量 很好 还行 响应速度 快 快 推理能力 很强 还行 适合场景 专业开发 日常基础开发 我的看法： 如果你是专业开发者，天天用，那就老老实实买 Claude 如果像我这样，日常写写博客、改改代码，GLM-4 完全够用 省下的钱买Gemini不香吗？ 常见问题Q1: 会被封号吗？A：目前没听说有被封的，但建议不要太频繁调用，正常使用没问题。 Q2: 额度够用吗？A：我平时写博客、改代码，用了一周还剩一大半。如果你不是重度用户，肯定够。 Q3: 比原版差多少？A：说实话，日常使用感觉不出太大差别。特别复杂的任务可能会差一些。 Q4: 稳定吗？A：大部分时间很稳定，偶尔会抽风，多试几次就好。 Q5: 支持 GPT 吗？A：理论上支持所有兼容 OpenAI API 的模型，但我只试了 GLM-4。 进阶技巧技巧1：设置快捷命令如果你经常用某个功能，可以设置个快捷命令： 1alias cc=’claude’ 这样以后输入 cc 就能用了。 技巧2：配合其他工具可以把 GLM-4 接到其他工具上，比如： VS Code 插件 JetBrains 插件 自己写的脚本 只要支持自定义 API，都能用。 20刀/月 GLM-4 免费 省下的钱买排骨它不香吗？ 适合人群 ✅ 学生党、白嫖党 ✅ 日常轻度使用 ✅ 想体验 AI 但不想花钱 ❌ 重度专业用户（建议买正版） 最后说两句其实折腾这个，一方面是为了省钱，另一方面也是想看看国内的大模型到底怎么样。 用下来感觉，GLM-4 作为平替是合格的。虽然跟 Claude 比还有差距，但对于我们这种普通用户，完全够用了。 而且，免费这两个字，真的很香！
